# Getting Started with AutoBot

**Your data. Your AI.** AutoBot is a self-hosted, agentic AI platform you own: a small,
solid core, a Service Lifecycle Manager (SLM) that runs the hard infrastructure for you,
and modules you install on top. Everything — your data, memory, agents, and knowledge
graph — runs on *your* infrastructure, pointed at any model you choose.

> **Canonical guide.** The complete, maintained getting-started walkthrough now lives at
> [Getting Started](../GETTING_STARTED_COMPLETE.md). This page is a short map into it and
> the surrounding documentation.

## What you can do

AutoBot is agentic — it talks, sees, and acts, all on hardware you control:

- **Chat and voice** — converse in text or hands-free voice against your own models
- **Browser and desktop control** — vision-in-the-loop browser automation and computer
  control, with human takeover
- **Human-in-the-loop approvals** — pause the agent on a proposed plan and resume only
  after you confirm
- **Visual workflow builder** — compose multi-step agent workflows on a drag-and-drop
  canvas
- **Knowledge graph** — institutional memory built from every conversation, document,
  and node
- **Multi-user + RBAC** — role-based access control for teams
- **Modules** — install AutoBot LLC (agents that work together as a company), the
  Transcriber, and Codebase Analytics *(work in progress)* on the core
- **Service Lifecycle Manager (SLM)** — deploys, operates, and scales the underlying
  infrastructure for you
