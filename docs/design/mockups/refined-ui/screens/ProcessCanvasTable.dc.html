Process canvas

The process library: one row per process, however many workflows use it. Think of a film script: people and agents are the actors, they get roles, roles perform workflows, and workflows are made of processes. Every process also has an owner role, and a routine can run it on a schedule as that role. Select several rows to edit them together.
