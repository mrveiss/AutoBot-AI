With an empty query and scope All, each group shows its top 5; the count tells people the rest is a keystroke away. Group order is fixed: Recent, Actions, Navigate, Agents, Knowledge documents, Settings.

Rules: Disabled rows stay visible with the reason in words and are skipped by ↑ ↓. Loading and errors are per group, announced once in the live region; never block the whole palette on one slow source.

Accessibility & behaviour contract

Use for: implementation review checklist
ARIADialog: role="dialog" aria-modal="true" with a labelled title. Input: role="combobox" aria-controls aria-expanded aria-autocomplete="list" aria-activedescendant. Results: role="listbox" with labelled role="group" sections and role="option" aria-selected.
FocusOn open, focus the input and make the page behind inert. Focus is trapped inside the dialog; on close it returns to whatever opened it (trigger or the element that had focus before Ctrl K).
Keys↑ ↓ move and wrap, Home / End jump, ↵ opens, Ctrl ↵ opens in a new tab, Tab / Shift Tab cycle scope, Backspace on an empty input leaves a nested step, Esc goes back, clears, then closes.
AnnounceA polite live region reports “12 results”, “No results for …” and action outcomes (“Queued run for research-agent”). Don't announce on every keystroke: debounce 300 ms.
DoKeep group order stable, highlight the matched text, remember the last 3 searches per user, and fall back to Chat with the query instead of a dead end.
Don'tRun destructive actions straight from the palette (open the confirm screen instead), nest more than one step deep, or hijack Ctrl K inside code editors and chat inputs that use it.
