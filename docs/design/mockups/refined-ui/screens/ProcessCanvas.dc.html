Process canvas

Think of it as a film script. People and agents are the actors, they get roles, roles perform workflows, and workflows are made of processes. A process is a reusable building block, so many workflows can use the same one. Roles also hold skills and meta skills, because some processes need them. Pick a workflow to see how work moves between its processes.
