  • Unit in the subtitle and on the top tick; never only in the tooltip.
  • Max 3 significant digits on axes; full precision in tables and tooltips.
  • Numbers in tables right-aligned, tabular figures (.num).

Never color-only meaning

  • Series: fill + pattern (HC/Mono), dash + marker shape for lines.
  • Thresholds: dashed line with a written label ("Target 400 ms").
  • Alerts: S5 / --bar-alert mark plus a word — "over", "alert", "Poor".
  • Direction: "up 8.2%", "down · better" — not just ▲ / ▼ or green / red.
  • Outline: every mark has a 1px var(--stroke) edge.

Accessibility & interaction

  • Static chart: role="img" + aria-label stating the takeaway and key values.
  • Interactive marks: focusable buttons with full-value aria-label; tooltip on hover and focus, Esc closes.
  • Every chart has a working "View as table" toggle (aria-pressed, captioned table).
  • Loading: aria-busy + status text; error: role="alert".
  • Respect prefers-reduced-motion; no animated entrances.
