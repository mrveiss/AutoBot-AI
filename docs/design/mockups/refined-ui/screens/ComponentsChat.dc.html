Citations & sources

Use for: Knowledge / web sources behind a RAG answer, with inline [n] markers

Contextual retrieval cut failed lookups by roughly a third in our tests 1, with reranking adding a further gain on long PDFs 2.

Rules: reliability is always spelled out (High / Medium / Low) next to match %; low-reliability web sources say "unverified". Inline markers are links to the card with aria-label "Source n". Collapse to "Sources · n" under the bubble when more than 4.
