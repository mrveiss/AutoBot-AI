| [[confidence-gated-decision-loop-harness]] | A confidence-gated finite-action agent loop over a decision-only "reflex" model — source analysis. The model cannot write text, call a tool, plan or remember, so the harness declares every action and every parameter value as a finite set before each call, and a free-text parameter fails at load time. Transferable, model-agnostic mechanisms: weakest-link confidence gating against risk-tiered thresholds (read 0.5 / write 0.7 / destructive 0.9), enforcement by omission (an infeasible action is absent from the question set, not refused), an exhaustive closed set of typed terminal reasons with `finish`/`escalate` as actions rather than prose, a structured handoff (state + questions + answers + weakest judgment + missed threshold) on every give-up, ordered and trace-recorded context degradation, distribution-preserving traces, stuck detection by observation hash, and environment-declared objectives read by a domain-agnostic outer loop. Hidden costs: total single-vendor model lock-in with no degradation path, the action space as a permanently maintained artifact whose drift is silent, and the environment's wording as the real tuning surface. Own-code findings in the source: `guards` (`is_safe`, `needs_human`) asked every step and read by nothing, `two_request` parsed and never used, a swallowed `OSError` on the trace write, candidate lists silently cut to the first 255 in dict order, and an objective DSL that reports zero failures for an unparseable predicate. No CI (`.github/` is images only), a handful of commits, bus factor 1, benchmark n=5 on the package's own toy fixture with the promised LLM-harness comparison arm absent. Phase 2 complete: our calibration-provenance marker (`Calibration.SELF_REPORTED` vs `MEASURED`, with an enforced exclusions test), repetition keyed on *(call, result)* with reset-on-change, refusal-with-an-argument (verifier rationale + refutation probability threaded into the approval payload, and a degraded verifier labelled `degradation=call_failed` rather than `prob=0.00`), human-only approval that refuses agent tokens, and indexed browser controls **with** staleness detection are all ahead of the source. The reframing fact: `agent_loop/` is not the production path (#14031), so every mechanism was checked twice — does it exist, and does it exist where requests go. Result: we own several mechanisms in the wrong place — a typed-decision seam (`llm_shared/decisions.py`, #17308) whose probabilities nobody thresholds, a give-up door that opens on input complexity instead of on giving up, and a terminal-reason enum in the loop that does not run beside ten free-text status strings in the one that does. 2 adoptions (1 where the source is simply ahead: report the tool you could not compile, with the reason), 3 adopt-with-conditions (one correctly blocked on a calibration measurement we have already told ourselves we have not made), 3 rejected — enforcement-by-omission vetoed because a per-turn tool list would break the prefix cache #17278 exists to protect. 8 findings already filed (witnessed, incl. a correction posted to #14031: the pre-action verifier now **does** have a production caller), 5 filed (#17466, #17467 → #13227; #17468, #17470 → #17271; #17469 → #17217) |
