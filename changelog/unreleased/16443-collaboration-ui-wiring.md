Collaborative chat sessions now have a working "who's here" panel: a live participant list, activity feed, and secret-sharing notifications, reachable from a new panel toggle next to the file panel in the chat header. Inviting a collaborator, seeing who's online, and sharing a secret with everyone in the session now actually work end-to-end.
