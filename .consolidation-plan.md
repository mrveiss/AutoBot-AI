# MVA-62: LLM Providers Consolidation Plan

## Current State Analysis

### Existing Code Structure
- **llm_providers/** - ~80% duplicate implementations
  - AnthropicProvider, OpenAIProvider, OllamaProvider, etc.
  - BaseProvider interface
  - ProviderRegistry
  - Has OTel in some providers (openrouter, nous_portal)
  
- **llm_interface_pkg/adapters/** - Thin wrappers
  - AnthropicAdapter, OpenAIAdapter, OllamaAdapter, etc.
  - Currently delegate to llm_providers/ implementations
  - test_environment() diagnostic logic
  
- **llm_interface_pkg/providers/** - Standalone implementations
  - ollama.py - has OTel tracing (#697), circuit breaker
  - transformers_provider.py

### Callsite Analysis (33 llm_providers imports)
- llm_multi_provider.py - re-exports providers (backward compat)
- llm_interface_pkg/adapters/*.py - delegates to llm_providers
- api/chat_compare.py, api/openai_compat.py - use provider_registry
- tests/ - test-only imports
- RLM stack - uses ollama_helpers

## Consolidation Strategy

### Phase 1: Establish llm_interface_pkg as Canonical Home
1. **Keep llm_interface_pkg/adapters/** as the primary API surface
   - Reason: Adapters are the high-level interface, have diagnostic methods
   - They will directly implement vs. delegating

2. **Consolidate implementations into llm_interface_pkg**
   - Move BaseProvider → llm_interface_pkg/base_provider.py (new)
   - Move ProviderRegistry → llm_interface_pkg/provider_registry.py (new)
   - Enhance with OTel tracing where missing
   - Keep provider implementations as-is (adapters delegate to them)

### Phase 2: Migrate Callsites
1. Change llm_multi_provider.py re-exports to import from llm_interface_pkg
2. Update api/ endpoints to import from llm_interface_pkg
3. Update RLM stack (think_tool.py, evaluator.py, etc.)
4. Update adapters to import from llm_interface_pkg/base instead of llm_providers/base

### Phase 3: Cleanup
1. Delete llm_providers/ directory
2. Verify no remaining imports of llm_providers
3. Run tests: `pytest tests/test_llm*.py tests/test_openai*.py -v`

## Key Decisions

- **Keep or delete adapters?** KEEP - they provide test_environment() diagnostic logic needed by api/adapters.py
- **Where do providers live?** llm_interface_pkg/providers/ (new subdir or stay in root?)
- **BaseProvider location?** llm_interface_pkg/base_provider.py to avoid circular imports
- **Registry location?** llm_interface_pkg/registry.py

## Risk Assessment

- **Medium** - touching core LLM routing logic
- **Mitigation**: Run full LLM test suite before/after, verify adapter diagnostics still work
