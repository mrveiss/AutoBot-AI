PROJECT SUMMARY
===============
Built a production-ready CausalRelationshipExtractor cognifier that extracts 
explicit causal relationships ("X CAUSES Y under condition Z") from documents,
distinguishing causality from correlation. Integrates seamlessly with AutoBot's
ECL (Extract, Cognify, Load) knowledge pipeline.

DELIVERABLES CREATED
====================

1. CausalEdge Data Model (98 lines)
   File: /autobot-backend/knowledge/pipeline/models/causal_edge.py
   
   - Pydantic model representing causal relationships
   - Fields: source/target names, effect_type, condition, confidence, evidence
   - 8 effect types: CAUSES, ENABLES, PREVENTS, AMPLIFIES, REDUCES, INHIBITS, 
     ACCELERATES, DECELERATES
   - Confidence scoring: 0.0-1.0 (1.0=explicit, <0.7=inferred/rejected)
   - Evidence tracking: preserves supporting text + source chunk IDs
   - Human-readable formatting: to_causal_string()

   File: /autobot-backend/knowledge/pipeline/cognifiers/causal_relationship_extractor.py

   ✓ LLM-guided extraction (high precision) for small datasets
   ✓ NLP fallback mode (lightweight) for bulk ingestion
   ✓ Auto mode selection: LLM for <500 chunks, NLP for ≥500
   ✓ Explicit correlation filtering: rejects "and", "correlated", "associated"

   NLP Keywords: 18 causal verbs with pattern-based extraction
   Batch Size: Configurable (default=5 chunks/call)

DESIGN DECISIONS
================

1. Confidence Thresholds
   - 0.9-1.0: Explicit causality ("X causes Y")
   - 0.7-0.85: Strong inference (carefully worded causal statements)
   - <0.7: Rejected (vague, correlational, or uncertain)

2. Mode Selection Logic
   - LLM for <500 chunks: Better precision, slower
   - NLP for ≥500 chunks: Fast, suitable for bulk ingestion
   - Explicit override: Always respected when specified

3. Condition Storage
   - Preserved as text: "when X", "under Y conditions"
   - Enables fine-grained causal reasoning
   - Example: "cache_ttl reduces latency when cache is enabled"

4. Bidirectional Causality
   - Rare in practice (nearly all causal links are directional)
   - Supported but typically false (causality implies direction)
   - Could be true for mutual reinforcement (e.g., positive feedback)

5. Graph Storage (Future)
   - Placeholder in query_causal_path()
   - Ready for Redis Graph integration
   - ChromaDB metadata fallback possible
