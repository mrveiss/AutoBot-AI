AutoBot is free and open under Apache-2.0 — use it, build on it, profit from it,
no permission needed. If it helps you build something that makes money, please
consider giving back so the project survives: a sponsorship, a fix, a case study,
or production support. There's no obligation — just an appeal from one builder to another.

Every contribution, however small, directly funds future development, keeps the
project maintained, and helps ensure AutoBot stays available, improving, and free
for everyone.

## Support tiers

AutoBot is free to run forever. Paid **production support** is how the project stays
funded and maintained — you pay for our time, guarantees, and compliance work, never
for permission to use the software:

- **Community — Free.** Self-host, modify, build, and profit under Apache-2.0.
  Support via [GitHub Issues](https://github.com/mrveiss/AutoBot-AI/issues) &
  [Discussions](https://github.com/mrveiss/AutoBot-AI/discussions).
- **Production Support** — guaranteed security patching, version-pinned stable releases,
  defined SLA response times, priority bug fixes, and upgrade assistance for companies
  running AutoBot in production.
- **Compliance Pack** — NIS2 / ISO 27001 documentation, security architecture overview,
  hardening guide, and audit-support materials (builds on AutoBot's existing
  [security framework](docs/security/SECURITY_FRAMEWORK.md)).
- **Vendor / OEM** — reselling AutoBot-as-a-service requires a separate commercial
  agreement; contact us to discuss.

**Contact:** production-support contact path pending — tracked in

## Ways to give back

- **Sponsor community development** — funds the free, open core:
  - [GitHub Sponsors](https://github.com/sponsors/mrveiss)
  - [Ko-fi](https://ko-fi.com/mrveiss)
- **Production support & compliance** — see [Support tiers](#support-tiers) above.
- **Contribute code or docs** — see [CONTRIBUTING.md](CONTRIBUTING.md).
- **Star &amp; share** — [star the repo](https://github.com/mrveiss/AutoBot-AI) and tell
  someone who'd find it useful.

You're never paying for permission to use the software — only for our time, guarantees,
and compliance work. The software itself is, and stays, free.
